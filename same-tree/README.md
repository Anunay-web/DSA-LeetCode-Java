# Day 2: Same Tree

**Difficulty:** Easy

## Problem

Given the roots of two binary trees p and q, write a function to check if they are the same tree - structurally identical with the same node values.

## Example

```
Input: p = [1,2,3], q = [1,2,3]
Output: true
```
