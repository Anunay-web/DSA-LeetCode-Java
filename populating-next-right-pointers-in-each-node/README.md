# Day 9: Populating Next Right Pointers in Each Node

**Difficulty:** Medium

## Problem

Given a perfect binary tree where every node has a next pointer, populate each next pointer to point to its next right node, or null if there isn't one.

## Example

```
Input: root = [1,2,3,4,5,6,7]
Output: [1,#,2,3,#,4,5,6,7,#]
```
