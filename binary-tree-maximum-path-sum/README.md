# Day 17: Binary Tree Maximum Path Sum

**Difficulty:** Hard

## Problem

Given the root of a binary tree, return the maximum path sum of any non-empty path (a path need not pass through the root).

## Example

```
Input: root = [-10,9,20,null,null,15,7]
Output: 42
```
