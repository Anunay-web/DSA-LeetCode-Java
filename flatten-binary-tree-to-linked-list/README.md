# Day 10: Flatten Binary Tree to Linked List

**Difficulty:** Medium

## Problem

Given the root of a binary tree, flatten it into a linked list in-place, following preorder traversal order, using the right child pointers.

## Example

```
Input: root = [1,2,5,3,4,null,6]
Output: [1,null,2,null,3,null,4,null,5,null,6]
```
