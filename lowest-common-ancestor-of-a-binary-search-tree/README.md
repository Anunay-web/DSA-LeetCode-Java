# Day 14: Lowest Common Ancestor of a Binary Search Tree

**Difficulty:** Medium

## Problem

Given a binary search tree and two nodes p and q, find their lowest common ancestor (LCA) in the BST.

## Example

```
Input: root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
Output: 6
```
