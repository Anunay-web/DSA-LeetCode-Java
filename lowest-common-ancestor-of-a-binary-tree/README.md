# Day 15: Lowest Common Ancestor of a Binary Tree

**Difficulty:** Medium

## Problem

Given a binary tree (not necessarily a BST) and two nodes p and q, find their lowest common ancestor.

## Example

```
Input: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
Output: 3
```
